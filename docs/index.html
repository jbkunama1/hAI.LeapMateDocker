🔧 Environment Variables

  • LEAPMOTOR_PASS – App Passwort
  • LEAPMOTOR_PIN – 4-stellige PIN
  • DB_PATH – /data/leapmotor_mate.db
  • TZ – z.B. Europe/Berlin

ℹ️ Was ist LeapMotor-Mate?

Self-hosted Web-Dashboard für Leap-Motor-Fahrzeuge. Pollt Fahrzeugdaten, speichert sie in SQLite und stellt sie über ein Web-UI bereit. Dieses Repo liefert den fertigen Docker-Stack für Portainer – kein manuelles Clonen nötig.

⚙️ GitHub Actions Build

  • Workflow: .github/workflows/docker-build.yml
  • Bei jedem Push auf main → Image bauen
  • Push auf ghcr.io/jbkunama1/hai.leapmatedocker
  • Multi-arch: linux/amd64 + linux/arm64
  • Host-Build (docker-compose.portainer.yml) bleibt unverändert
